# Spam SMS Detection

## Overview

This project uses Machine Learning and Natural Language Processing (NLP) techniques to classify SMS messages as Spam or Ham (Legitimate Messages).

## Tech Stack

* Python
* Pandas
* Scikit-learn
* NLTK
* TF-IDF Vectorization

## Features

* SMS Text Preprocessing
* Spam Detection
* Feature Extraction using TF-IDF
* Machine Learning Classification
* Model Evaluation
